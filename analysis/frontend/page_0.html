ADB / Fastboot Commands
Separate information-only checks from actions that change your phone.


Connected DeviceNot scanned




Shows information only. No partitions or data are modified.


Actions — changes phone state
Run only on your own authorized device. Refresh and verify its current ADB/Fastboot mode before selecting an operation.


Reboot Systemadb reboot / fastboot reboot
Restarts the device normally; interrupts running apps.
Reboot Recoveryadb reboot recovery
Requests a restart into recovery mode. Not supported from every Fastboot state.
Reboot Bootloaderadb reboot bootloader
Restarts Android into bootloader/Fastboot mode.
Factory Reset (Wipe User Data)fastboot -w
Erases user data on compatible unlocked devices; irreversible. Does not remove account locks.
Erase Metadatafastboot erase metadata
Deletes encryption-related metadata; can make existing data unreadable.
Erase Userdatafastboot erase userdata
Erases the user data partition including apps and personal files.
